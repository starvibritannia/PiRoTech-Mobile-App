Kebijakan Privasi - PiRoTech Mobile App

PiRoTech Mobile App dikembangkan oleh JAMES Enterprise. Kebijakan ini menjelaskan bagaimana data Anda dikelola.

Data yang Kami Kumpulkan

  • Autentikasi: Kami menggunakan Firebase Authentication untuk mengelola sesi login Anda (menggunakan email dan password).
  • Data IoT: Kami menggunakan Firebase Realtime Database untuk menyimpan dan menampilkan data pemantauan IoT yang relevan dengan fungsi aplikasi.

Penggunaan Data

Data yang dikumpulkan digunakan semata-mata untuk menyediakan layanan aplikasi PiRoTech, mengamankan akun Anda, dan memastikan fungsionalitas pemantauan data IoT berjalan dengan benar.

Keamanan

Kami berkomitmen menjaga keamanan data Anda menggunakan standar keamanan dari Firebase (Google Cloud).

Kontak

Jika ada pertanyaan terkait kebijakan ini, silakan hubungi pengembang melalui repositori GitHub resmi kami.
