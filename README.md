# PiRoTech Mobile App 📱

Selamat datang di repositori resmi **PiRoTech Mobile App**! Aplikasi ini dikembangkan untuk memudahkan pemantauan dan interaksi data berbasis IoT/Mobile secara real-time.

## Tentang Projek 💡

PiRoTech adalah aplikasi mobile berbasis Flutter yang dirancang untuk monitoring data suhu pembakaran alat pirolisis plastik dengan integrasi perangkat IoT dan Firebase yang aman dan efisien.

## Fitur Utama ✨

- **Real-time Monitoring:** Pantau data secara instan melalui integrasi Firebase Realtime Database.
- **Autentikasi Aman:** Sistem login yang terintegrasi dengan Firebase Authentication.
- **Visualisasi Data:** Grafik interaktif untuk mempermudah pembacaan tren data.
- **Notifikasi Lokal:** Pemberitahuan penting langsung ke perangkat pengguna.

## Teknologi yang Digunakan 🛠️

- **Framework:** [Flutter](https://flutter.dev/)
- **Backend/Database:** [Firebase](https://firebase.google.com/) (Auth, Realtime Database)
- **State Management:** [-]
- **Language:** Dart

## Cara Menjalankan Projek 🚀

1. Pastikan Flutter SDK sudah terinstall di perangkatmu.
2. Clone repositori ini:
   `git clone https://github.com/starvibritannia/PiRoTech-Mobile-App.git`
3. Masuk ke folder projek:
   `cd PiRoTech-Mobile-App`
4. Jalankan perintah untuk mengunduh dependencies:
   `flutter pub get`
5. Jalankan aplikasi:
   `flutter run`
